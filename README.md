# Тёплое место

Сайт аренды тёплой беседки ручной работы в Анкудиновке, Нижний Новгород. Одна страница с онлайн-бронированием и отдельная страница для менеджера.

## Смотреть

- `preview.html` — автономная демо-копия. Открывается двойным кликом, картинки встроены, календарь бронирования работает на заглушке. Заявки из неё никуда не уходят.
- `index.html` — рабочая страница сайта.
- `admin.html` — страница менеджера: заявки, подтверждение, отмена, закрытие дат.

## Запустить у себя

Пошаговая инструкция без техничики: **[КАК-ЗАПУСТИТЬ.md](КАК-ЗАПУСТИТЬ.md)**

Коротко: развернуть `backend/Code.gs` как веб-приложение Google Apps Script, вставить полученную ссылку в `config.js`, залить папку на любой статический хостинг.

## Как устроено

| Файл | Назначение |
|---|---|
| `index.html` | Лендинг: 10 секций, календарь с расчётом цены |
| `admin.html` | Панель менеджера, вход по паролю |
| `config.js` | Единственный файл для правки: адрес бэкенда |
| `backend/Code.gs` | Бэкенд на Google Apps Script: заявки в Google-таблицу, уведомления в Telegram и на почту |
| `photos/` | Изображения. Пока визуализации, заменяются реальными фото под теми же именами |
| `dev_server.py` | Локальный сервер для разработки с тем же API, что у бэкенда |
| `build_preview.py` | Собирает `preview.html` |

## Разработка

```
py -3 dev_server.py
```

Сайт на `http://localhost:8743`, панель менеджера на `/admin.html`. Пароль локального сервера задан в начале `dev_server.py` и предназначен только для разработки: он не имеет отношения к боевому паролю, который задаётся в `backend/Code.gs`.

## Что нужно сделать перед запуском

1. Заменить визуализации в `photos/` на реальные фотографии и убрать бейджи «Визуализация» из `index.html`.
2. Заменить телефон `+7 900 000-00-00` на настоящий в `index.html` и `admin.html`.
3. Развернуть бэкенд и вписать ссылку в `config.js`.
4. Задать надёжный пароль в `backend/Code.gs`: по нему открывается доступ к контактам гостей.
